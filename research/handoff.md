## What landed since the last handoff, and why each thing exists

- **#230 / #234 `9b3a123` — an operator's authorization is no longer a sentence.** Reopening an issue that owes authorization appends exactly one durable grant; `delegate` spends it *after* the concurrency claim succeeds (a call refused because another worker owns the issue can't burn one) and records `replanSource:"operator"` with the granting requestId. Prose still unlocks the guard — blocking legitimately re-scoped work was #222's explicit acceptance failure — but records `replanSource:"model"` and logs that no human stands behind it. Grants are never issued for an issue with no prior abort, never for a **stopped** one (#141 stays intact), and buy one attempt each. My own `#226` test asserted reopen touches `BudgetLedgerDoc` *not at all* — a proxy for "can't restore budget" — so it was **refined** to pin the counters byte-for-byte while allowing grants, plus the opposite-direction test (fresh issue ⇒ zero writes).
- **#236 `gates/deploy-posture.mjs` — policy-vs-disk drift.** Each instance's `config/gates.json` is written at boot by whichever build ran, so it describes *that* build; if `main` changes the policy and nobody restarts, nothing says so. ## Things that will bite you

- **A verification step must name a file that exists, and be the only way to do that check.** I "verified" a deploy by running `gates/gate-posture.mjs` — a filename I invented, never in this repo — through `… 2>&1 | tail -2`, which reports `tail`'s status: Node printed `MODULE_NOT_FOUND` and the step exited **0**, and I recorded "posture verified". Both traps were already documented here an hour earlier. A habit has no failure mode; a command does.
- **Never take an exit code through a pipe.** `cmd | tail`, `cmd | grep …; echo $?` — all report the last stage. Use `set -o pipefail`, or run the command and check `$?` before piping. Same family: never put backticks in a double-quoted shell string (a `gh issue close --comment` of mine ate its own text that way).
- **A main guard can silently no-op.** `import.meta.url === pathToFileURL(process.argv[1]).href` is false for symlinked invocation paths — every macOS `/var/folders/…` temp dir resolves to `/private/var/…` — so the script ran nothing and exited 0 with **no output**. Realpath both sides (`fleet/verify-deploy-posture.mjs` does, with a regression test that invokes through a symlink and demands output).
- **Never `git checkout <file>` to undo a test mutation** when that file has uncommitted work: it destroys the work. I did this to two files mid-feature and re-applied from scratch. Use `cp` backups, and revert mutations with targeted edits.
- **A reopen reason is injected as authoritative operator context.** Write it as a fact you have already made true in the issue body, or as explicit operator intent. "Slice reduced to X" came back as the model's assertion that X had happened (#230); #238 is the remaining piece.
- **Aborts: `taskId` settles a task, `conversationId` stops the loop.** Include `issueNumber` in the abort body or the intervention is recorded nowhere (the code refuses to guess). Operator aborts cost nothing by design (#141) and never trigger `requiresReplan`.
- **Current document state lives in `document_revisions` deltas**, not the last base snapshot; use a read-only connection (`file:…?mode=ro`).
- **Gates that collect nothing look like passing gates.** `registry-targets.mjs` and `behavior-probes.mjs` are libraries; `shutdown-handles.mjs` exits 0 without `--fleet`. Now also: any sub-gate whose exit code you consume must print a collection line, which is why the verifier FAILs on `exit 0` without one.
- **Never forbid a worker from touching test wiring.** eng#76's spec said "don't touch `package.json` scripts"; the worker produced a green test file that no CI job collected. If a task may add a test, its spec must permit registering it.
- **Example payloads must be inert.** `rm -rf ./node_modules`, never `rm -rf /`. The detector's own pattern list keeps the real string (it must match reality).
- **Approvals are per-file** (`sha1(tool + exact args)`). Prose no longer trips the floor, so multi-file runs are quiet; `merge_pr` still prompts, intentionally.
- **`/tmp` is not mounted into podman sandboxes** (use Node's `os.tmpdir()`); **`timeout` doesn't exist on macOS** (`gtimeout`).
- Still true from prior handoffs: never `pkill -f "server.mjs <port>"` from a shell whose own command line matches; stacked PRs land via the async merge REST API (`gh pr merge --admin` refuses stacks); drafts need `gh pr ready`; **a green suite is not evidence about the remote**; fleet restart = single SIGTERM, then verify orphans / lock released / `:9700` / `build.sha` / 3 children parented / 0 quarantine — or just run the command.
